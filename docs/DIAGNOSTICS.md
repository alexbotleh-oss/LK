# Б77 — единый контур диагностики

Назначение: собирать диагностику проекта и приложения так, чтобы ошибки можно было быстро локализовать без изменения рабочей логики.

## Контуры

1. **Project Diagnostic** — структура репозитория, обязательные каталоги, критические файлы, SHA/размеры, статические проверки.
2. **Application Diagnostic** — runtime ошибки JavaScript, unhandled rejection, состояние экранов, события сканера, состояние камеры, окружение HTTPS/secure context.
3. **Regression** — контроль того, что диагностика не изменяет бизнес-логику.

## Правило

Диагностический код не должен принимать бизнес-решения. Он только наблюдает, фиксирует и экспортирует данные.

Runtime-диагностика хранит события в памяти и localStorage и позволяет экспортировать JSON. Автоматическая запись в GitHub из браузера не используется: токен GitHub нельзя помещать в клиентское приложение.

## Запуск project diagnostic

```text
python scripts/project_diagnostic.py
```

Отчёт создаётся в `reports/`.

## Application diagnostic

Подключение:

```html
<script src="./src/web/diagnostics.js"></script>
```

Вызов:

```js
window.B77Diag.install();
window.B77Diag.event("scanner", "camera-open-request");
```

Экспорт:

```js
B77Diag.download();
```

Диагностический модуль специально не вызывает существующие обработчики приложения и не заменяет их.
