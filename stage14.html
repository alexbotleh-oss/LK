ℹ️ О программе

🍳 Что приготовить
Recipe Manager · HTML/PWA контрольный клиент
Build 47 · UI/PWA prototype
Для чего программа

Единое приложение для продуктов, рецептов, приготовления и покупок. HTML/PWA используется как контрольный интерфейс проекта перед переносом логики в Flet Android.

Основные функции
🧺 Продукты — наличие, категории, партии, сроки годности, штрихкоды и канонические продукты.
📖 Рецепты — ингредиенты, количества и единицы, порядок шагов, время, советы, КБЖУ.
🍳 Готовить — подбор по наличию продуктов с отдельным учётом доступности и диет.
🎲 Рулетка — выбор рецепта по активным фильтрам.
🛒 Покупки — недостающие продукты из рецептов и ручные покупки.
🍲 Lite Cook — 1–2 блюда, покупки, пошаговое приготовление и таймеры.
📷 Сканирование — Products / Shopping / QR с единым обработчиком результата.
📥 Импорт — WEB, PDF, JSON/TXT через staging → проверку → нормализацию → commit.
🥗 Диеты и типы питания — отдельные правила допуска/ограничения.
👪 Семейный обмен — экспорт/импорт с явным разрешением конфликтов.
💾 Резервные копии — backup/restore и откат.
▤ QR/штрихкоды — локальная база, история и связи с продуктами.
Lite Cook — логика

Выбираем 1–2 блюда → порядок старта → проверка наличия → ShoppingNeed → при необходимости покупки → возвращение к готовке. Показывается текущий шаг; таймер появляется только если у шага указано время. Для двух блюд максимум два одновременно работающих таймера.

Принципы проекта

Одна общая Core-логика для клиентов. Импорт не пишет напрямую в основную БД. Неоднозначные единицы и совпадения не угадываются. Для Flet рабочий сканер — только native Android.
